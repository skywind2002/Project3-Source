## 非均匀量化(Lloyd-max)算法实验记录

自己设计的量化器采取通网课上讲的Lloyd-Max算法，核心为以下两条规则(Lloyd-Max规定)：

- 分层电平在重建电平的重点
- 重建电平在分层区间的质心

对这两个结论进行反复迭代，在保证收敛的情况下就可以得到最佳的分层电平

代码在LloydMax.m中，已经封装为函数。
