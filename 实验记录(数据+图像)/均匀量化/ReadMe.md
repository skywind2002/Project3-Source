## 均匀量化器的参数设置

均匀量化器的任务是绘制均匀量化的PSNR-码流比特率图

以及改变步长绘制R-D图。



其他不变的参数为：

blockOption=2;   分块大小为8*8

vlcRadio=1；双符号编码

测试图像为lena_128_bw.bmp

**步长取了$2^1到2^7$一共7个数据，得到的图片如文件夹所示**
